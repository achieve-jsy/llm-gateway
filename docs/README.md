# 模型网关项目文档（docs/）

> 本目录是模型网关项目的**项目管理与战略级文档**：产品定位、技术架构、版本规划。
> 细粒度的需求规格 / 概要设计 / 详细设计 / 任务清单等**设计制品**由 `xspec/` 通过 xflow 工作流产出，二者职责清晰分离。

## docs/ 与 xspec/ 的关系

| 维度 | `docs/` | `xspec/` |
| :--- | :--- | :--- |
| 定位 | 项目级管理文档（产品、技术、版本） | 模块级设计制品（spec / hld / design / contracts / task） |
| 受众 | 全员、业务方、新人 | 开发执行、架构评审 |
| 颗粒度 | 战略 / 路线图级 | 任务可执行级 |
| 更新频率 | 版本里程碑 + 重大决策 | 每个 xflow 变更 |
| 维护方式 | 人工编辑 + 评审 | xflow 命令产出（`/xf:clarify` → `/xf:archive`） |
| 修改约束 | 直接 PR 修改 | 遵守 xflow 活跃变更保护与门禁 |

> 一句话：**`docs/` 回答「我们要做什么 / 为什么这么做 / 什么时候做」，`xspec/` 回答「具体每个模块怎么设计、怎么实现」。**

## UI 规范

项目级 UI 设计规范放在 `docs/ui/` 下，供多个前端模块共享引用。

当前可用规范：

- `docs/ui/WattVision-UI-Guideline.md`：WattVision 电力监控界面的统一视觉与样式规范

使用建议：

- 全局视觉语言、配色、字体、布局原则放在 `docs/ui/`
- 模块级页面实现和交互特化仍写入 `xspec/changes/<module>/design.md`
