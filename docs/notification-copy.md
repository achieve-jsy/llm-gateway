# 通知文案总览（修改后）

> 本文档是**通知文案的唯一现状清单**，用于评审与回归。
> 内容不是手抄：预算告警、报表、对象名映射均由**真实代码执行**打印（临时测试调用内部构造函数），
> 其余为源码字面量逐条摘录并标注 `文件:行`。

---

## 0. 统一规则

| 规则 | 说明 |
|---|---|
| 时区 | 一律北京时间（`internal/notification/localtime.go`，`Asia/Shanghai`，缺 tzdata 时退化为 +08:00） |
| 内部标识 | 标题/正文**不得**出现 scope UUID、`member`/`dept_daily`/`tier`/`monthly` 等内部枚举 |
| 错误串 | 原始 Go/gorm/上游错误串**只进日志**，不进用户文案 |
| Markdown | 站内信保留 Markdown；邮件经 `notification.PlainText` 剥离（`**`→空、`- `→`· `、`> `→空） |
| 邮件主题 | 统一前缀 `[LLM Gateway] `，由调用方透传（`SendTextToWithSubject`） |
| RefID | UUID 仍写入 `RefType/RefID`（供前端跳转），**但不渲染给用户** |

### 对象名映射（`budgetScopeObjectLabel`，真实执行输出）

| scope_type | 能解析到名称 | 解析不到 |
|---|---|---|
| `company` | 全公司 | 全公司 |
| `studio` | `X-Lab大模型·工作室预算` | 工作室预算 |
| `dept_daily` | `X-Lab大模型·成员日常预算` | 部门成员日常预算 |
| `dept_service` | `X-Lab大模型·程序服务预算` | 部门程序服务预算 |
| `member` | `X-Lab大模型 的个人额度` | 成员个人额度 |
| 其他 | `X-Lab大模型` | 预算 |

### 周期词（`budgetAlertPeriodWord`）

`daily → 今日`　`weekly → 本周`　`monthly → 本月`

## 3. 扩容申请流程（站内信 + 邮件）

正文模板（结构化多行，main 上已由 `expansionNotifyBody(ctx, request, detail, requesterName, approverName)` 产出）：
```
申请对象：{对象}
申请人：{姓名}                ← member 级申请省略此行（对象名已含姓名）
额度变化：当前上限 ${现值} → 目标上限 ${目标值}   ← 该维度未配额度时显示「当前未配置额度」
{补充说明}
审批人：{姓名}                ← 审批类通知才有
申请时间：{北京时间}           ← 原先输出 UTC，现统一北京时间
```
其中 `{对象}` = 名称或类型标签 [ ` · {模型等级名}` ] ` · {总预算|模型等级}` ` · {日|周|月}额度 · {临时|长期}`

| 通知类型 | 标题 | 补充说明 |
|---|---|---|
| `expansion_submitted`（成员） | 新的扩容审批申请 | `申请原因：{用户填写}` |
| `expansion_submitted`（平台级） | 新的平台级扩容审批申请 | `申请原因：{用户填写}` |
| `expansion_decision` | 扩容申请状态更新 | `审批意见：{审批人填写}` |
| `expansion_decision`（升级） | 扩容申请已升级审批 | `审批意见：{审批人填写}` |
| `expansion_rejected` | 扩容申请已驳回 | `驳回意见：{审批人填写}` |
| `expansion_approved` | 扩容申请已批准并生效 | `申请原因：{用户填写}` |
| `expansion_apply_failed` | 扩容申请生效失败 | `生效失败原因：配置下发未成功，请到「扩容申请」详情页查看并重试。`（**原文**：`生效失败原因：` + 原始错误串，现只进日志） |

示例（真实渲染）：
```
申请对象：芮宇潇 · Claude系列 · 模型等级 · 月额度 · 长期
申请人：芮宇潇
额度变化：当前上限 $100.00 → 目标上限 $300.00
申请原因：研发需要更大额度
申请时间：2026-09-17 14:32
```

## 4. 预算生命周期（站内信 + 邮件）

| 通知类型 | 标题 | 正文 |
|---|---|---|
| `expansion_restored` | 临时扩容已到期 | `临时额度已于 2026-09-18 05:55 到期，当前额度恢复为届时生效的长期基础额度。` |
| `budget_schedule_applied` | 预算计划已生效 | `本月预算计划已于 2026-09-18 05:55 生效。`（周期词随计划：今日/本周/本月） |
| `budget_schedule_failed` | 预算计划生效失败 | `本月预算计划于 2026-09-18 05:55 生效失败，请进入预算管理检查配置后重新提交。`（**原文**：正文携带执行器返回的英文原始错误串） |

> 时间全部为北京时间（`formatNotificationTime`：UTC `2026-09-17 21:55` → 展示 `2026-09-18 05:55`）。
