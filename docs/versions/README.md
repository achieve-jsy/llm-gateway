## STATUS 字典

| STATUS | 含义 |
| :--- | :--- |
| 📝 Planning | 规划中 |
| 🔒 Frozen | 范围冻结，进入开发 |
| 🚧 In Progress | 开发中 |
| 🧪 Testing | 测试中 |
| ✅ Released | 已发布 |
| ⏸️ Paused | 暂停 |
| ❌ Cancelled | 取消 |

## 版本文档模板

> 新建版本时，复制下面模板到 `vX.Y.Z.md`，按需填充。

```markdown
# vX.Y.Z — <版本主题>

| 项 | 值 |
| :--- | :--- |
| 版本号 | vX.Y.Z |
| 周次 | Wn |
| STATUS | 📝 Planning / 🔒 Frozen / 🚧 In Progress / 🧪 Testing / ✅ Released |
| 计划起止 | YYYY-MM-DD → YYYY-MM-DD |
| 负责人 | TBD |
| 关联 xspec change-id | TBD（开发启动后填） |
| 关联 PR | TBD |

## 1. 版本主题
<一句话>

## 2. 目标
<解决 PRD 的哪些核心价值；要达到的可衡量结果>

## 3. 范围（in-scope）
- [ ] 功能 1
- [ ] 功能 2

## 4. out-of-scope（明确不做）
- 功能 X（推迟到 vX.Y）
- 功能 Y（不在本项目范围）

## 5. 任务清单（粗粒度）
> 细粒度任务在 xspec/<module>/task.md

| :-: | :--- | :--- | :--- | :--- |
| T1 | … | … | … | ⏳ |

- [ ] 标准 1（可测量）
- [ ] 标准 2

## 7. 依赖与风险
| 项 | 类型 | 说明 | 缓解 |
| :--- | :--- | :--- | :--- |

## 8. 进展记录
| 日期 | 更新 |
| :--- | :--- |

## 9. 变更记录（同版本范围调整）
| 日期 | 变更类型 | 内容 | 决策人 |
| :--- | :--- | :--- | :--- |

## 10. 复盘（Released 后补充）

- 没做好的：
- 下次改进：
- 实际 vs 计划工期：
```
