# ops-console 需求变更 — CHG-20260523-001

> 基线：xspec/modules/ops-console/spec.md (v1.1)

## 变更摘要

新增员工 SSO 登录（OIDC 回调页）、Key 自助管理页面（创建/查看脱敏/禁用/删除）、模型可用列表页面（基于 /v1/me/models）、首页欢迎与使用文档（curl 与 OpenAI SDK 示例）。

## 新增需求

### US-LOGIN-01 — 员工 SSO 登录 (P0)

**作为**员工，**我想要**通过公司 SSO 登录平台，**以便**使用公司统一账号进入 Key 管理和模型查询等功能页面。

**功能说明**：
- 平台提供"登录"入口，点击后跳转至公司 SSO 认证页面
- SSO 认证完成后回调至平台指定页面，平台处理认证结果并写入员工身份（含用户信息与部门归属）
- 登录成功后跳转至平台首页
- 若 SSO 认证失败或回调异常，平台展示明确的失败提示，不进入任何功能页面

**异常与边界**：
- SSO 认证服务不可达 → 登录页展示"认证服务暂时不可用，请稍后重试"，不暴露内部错误细节
- SSO 回调中认证结果无效或缺失 → 回调页展示"登录失败，请重新尝试"，不自动写入不完整的身份数据

### US-KEY-PAGE-01 — Key 自助管理页面 (P0)

**作为**员工，**我想要**在"我的 Key"页面自助管理我的 API Key，**以便**创建、查看、禁用或删除我的 Key 而无需联系管理员。

**功能说明**：
- 页面标题为"我的 Key"，仅展示当前登录员工名下的 Key 列表
- Key 列表每个条目展示：Key 脱敏值（仅末尾 4 位可见）、创建时间、当前状态（启用/禁用）
- 提供"创建 Key"按钮，点击后创建新 Key，创建成功弹窗展示 Key 明文并明确提示"此明文仅展示一次，请立即复制保存"
- 每个启用状态的 Key 提供"禁用"操作入口
- 每个禁用状态的 Key 提供"启用"和"删除"操作入口，删除操作需二次确认

**异常与边界**：
- 员工名下无 Key → 列表区展示空状态文案"暂无 Key，点击创建按钮生成你的第一个 Key"
- 员工 Key 数量达到上限 → "创建 Key"按钮置灰不可点击，提示已达数量上限 [待确认: 单用户最大 Key 数量上限值]
- 禁用操作与并发调用同时发生 → 页面操作结果以服务端返回为准，操作成功后列表即时刷新状态

### US-MODEL-PAGE-01 — 模型可用列表页面 (P0)

**作为**员工，**我想要**查看当前身份下可用的模型列表，**以便**确认我可以调用哪些模型并获取调用方式。

**功能说明**：
- 页面标题为"可用模型"，展示当前登录员工经身份鉴权后可用的模型列表
- 模型数据来源于基于当前身份的模型查询能力，基于员工身份（User → Department）过滤
- 每个模型条目展示：模型名称、模型类型（对话补全/向量嵌入）、可用状态
- 列表中的模型均为当前员工实际可调用的模型

**异常与边界**：
- 当前身份无可用模型 → 页面展示空状态文案"当前身份暂无可用模型"
- 用户可用模型查询接口请求失败 → 页面展示"模型列表加载失败，请刷新重试"，不展示过期的缓存数据

### US-HOME-01 — 首页欢迎与使用文档 (P0)

**作为**员工，**我想要**在登录后看到欢迎信息和 API 使用文档，**以便**快速了解如何用 Key 调用网关。

**功能说明**：
- 首页展示欢迎信息（含当前登录员工姓名和所属部门）
- 使用文档区展示两种调用示例：curl 命令示例和兼容 OpenAI 协议的 SDK 调用示例
- 示例中包含关键要素：API Key 使用位置、请求地址、模型名称选择
- 文档区提供快速跳转至"我的 Key"和"可用模型"页面的入口

**异常与边界**：
- 员工尚未创建任何 Key → 使用文档区额外提示"请先前往我的 Key 页面创建 API Key"
- 员工当前无可用模型 → 使用文档区额外提示"当前身份暂无可用模型，模型名称需从可用模型页面获取"
