# ops-console 需求变更 — CHG-20260521-002

> 基线：xspec/modules/ops-console/spec.md (v1.0)

## 变更摘要

渠道管理页新增"同步模型"按钮和同步结果弹窗，支持过滤、勾选、一键全选后批量注册模型。

## 新增需求

### US-SYNC-UI-01 — 同步模型按钮 (P0)

**作为**平台管理员，**我想要**在渠道列表的操作列中看到"同步模型"按钮，**以便**快速触发该渠道的模型同步。

**功能说明**：
- 渠道列表每行操作区新增"同步模型"按钮
- 点击后调用后端同步接口，显示 loading 状态
- 同步完成后弹出同步结果弹窗

**异常与边界**：
- 渠道禁用状态时按钮置灰不可点击
- 同步失败时显示错误提示，不弹出结果弹窗

### US-SYNC-UI-02 — 同步结果弹窗 (P0)

**作为**平台管理员，**我想要**在同步结果弹窗中看到拉取到的模型列表并能勾选注册，**以便**选择性地注册需要的模型。

**功能说明**：
- 弹窗标题显示"同步模型 — {渠道名称}"
- 顶部统计栏：新增 X 个 / 已存在 X 个 / 已下架 X 个
- 搜索框：按模型名称关键词实时过滤
- 模型列表：checkbox + 模型名称 + 状态标签（新增/已存在/已下架）
- "已存在"的模型 checkbox 禁用（不可重复注册）
- "已下架"的模型显示为已自动禁用状态
- 底部操作栏：一键全选（仅选"新增"状态）+ 确认注册按钮 + 取消
- 确认注册后显示"成功注册 X 个模型"提示

**异常与边界**：
- 模型列表为空 → 显示"该渠道暂无可同步的新模型"
- 模型数量超过 50 → 列表内滚动，不分页（弹窗内）
- 不支持同步的渠道类型 → 弹窗替换为提示信息"该渠道类型不支持自动同步，请手动注册或使用预置模型"
