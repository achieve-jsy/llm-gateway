# ops-console 需求变更 — CHG-20260525-001

> 基线：xspec/modules/ops-console/spec.md (v1.2)

## 变更摘要

新增模型组管理页面：平台管理员可在后台创建/编辑/删除模型组（组名、描述、路由策略）、管理组内模型（添加已有模型/设置优先级或权重/移除模型）、查看组内模型列表。前端消费 control-plane 新增的模型组 CRUD 接口。

## 新增需求

### US-GROUP-UI-01 — 模型组列表页 (P0)

**作为**平台管理员，**我想要**在后台看到所有模型组的列表，**以便**快速了解当前已配置的模型组及状态。

**功能说明**：
- 导航新增"模型组"菜单，点击进入模型组列表页
- 列表展示每个模型组：组名称、路由策略类型、组内模型数量、启用状态
- 列表支持按组名称搜索
- 每个模型组提供"编辑"和"删除"操作入口

**异常与边界**：
- 当前无任何模型组 → 列表展示空状态文案"暂无模型组，点击创建第一个模型组"
- 删除操作需二次确认弹窗，确认后执行删除
- 模型组列表数据加载失败 → 展示"加载失败，请刷新重试"，保留页面结构

### US-GROUP-UI-02 — 模型组创建与编辑面板 (P0)

**作为**平台管理员，**我想要**在创建或编辑面板中配置模型组，**以便**设定组的名称、描述和路由策略。

**功能说明**：
- 创建/编辑面板包含：组名称（必填，最多 64 字符）、组描述（选填）、路由策略单选（轮询/优先级/加权）
- 策略选择为"优先级"时，提示管理员在添加模型时需指定优先级数字
- 策略选择为"加权"时，提示管理员在添加模型时需指定权重值
- 提交时校验组名称不为空且长度合规

**异常与边界**：
- 组名称与已有组重复 → 提交后由服务端返回错误，前端展示具体错误原因
- 组名称超长 → 前端输入框限制 64 字符，超出不可输入
- 编辑时切换策略类型 → 展示提示"切换策略类型将清除已有模型的策略参数"

### US-GROUP-UI-03 — 组内模型编辑面板 (P0)

**作为**平台管理员，**我想要**在模型组编辑面板中管理组内模型，**以便**添加、配置参数或移除模型。

**功能说明**：
- 模型组编辑面板内嵌"模型列表"子区域，展示当前组内模型
- 组内模型每个条目展示：模型名称、策略参数（优先级数字或权重值，轮询策略时为空）
- "添加模型"按钮触发模型选择器：展示全部已注册模型（含搜索过滤），支持多选，已加入当前组的模型默认勾选置灰
- 优先级策略时，每个添加的模型需填写优先级数字（非负整数）
- 加权策略时，每个添加的模型需填写权重值（1-100 的整数）
- 每个模型条目提供"移除"操作

**异常与边界**：
- 当前无已注册模型 → "添加模型"按钮置灰，提示"当前无已注册模型，请先在模型管理中注册模型"
- 优先级策略下两个模型填入相同优先级 → 允许提交，在编辑区展示为两个相同数字
- 组内移除最后一个模型 → 组内模型列表变空，页面保留组的其他配置不变
