# ops-console 需求变更 — CHG-20260609-001

> 基线：xspec/modules/ops-console/spec.md (v1.0)

## 变更摘要

新增组织管理模块（树形视图、映射维护、角色管理）和分层用量看板（个人/管理两区 + 面包屑下钻），覆盖平台管理员、工作室/部门负责人、普通员工的差异化视角。

---

## 新增需求

### N1. 组织管理页（P0）

**US-ORG-01**（P0）作为平台管理员，我想要以树形视图查看完整组织结构，以便掌握公司→工作室→部门→员工全景

**UI 与交互**：
- 路由：`/admin/org`，侧边栏新增「组织管理」入口，仅 admin 可见
- 左侧树形导航：公司根节点 → 工作室 → 部门，点击节点右侧展示该节点详情（成员数、负责人、映射状态）
- 部门节点显示映射状态 badge：已映射（绿）/ 待映射（红）

**US-ORG-02**（P0）作为平台管理员，我想要维护部门↔工作室映射，以便让员工正确归集到工作室

**UI 与交互**：
- 路由：`/admin/org/mapping`
- 表格列：部门名、所属工作室（下拉可修改）、映射来源（导入/手工）、映射状态
- 「批量导入」按钮：上传 CSV → 预览 diff 表格（新增/变更/无变化三列）→ 确认写入
- 「未映射部门」红点数量角标，点击跳转过滤视图，可一键为每个待映射部门指定工作室

**US-ORG-03**（P0）作为平台管理员，我想要为员工指定工作室/部门负责人角色，以便建立管辖域层级

**UI 与交互**：
- 路由：`/admin/org/roles`
- 角色列表表格：用户名、邮箱、当前角色、管辖域、操作（卸任）
- 「指定负责人」表单：搜索员工姓名/邮箱 → 选择角色类型（studio_admin/dept_admin）→ 选择管辖域（工作室/部门下拉）→ 确认

### N2. 分层用量看板（P1）

**US-DASH-01**（P1）作为任意用户，我想要在个人看板查看自己的用量，以便了解个人消耗

**UI 与交互**：
- 个人看板与现有用量页复用，数据范围锁定 `user_id == 自己`
- 所有角色（含管理员）均可访问；不因身份而展示额外数据

**US-DASH-02**（P1）作为管理角色，我想要在管理看板查看管辖域内的用量排行，以便掌握部门/工作室消耗

**UI 与交互**：
- 路由：`/admin/usage/dashboard`，仅管理角色（dept_admin/studio_admin/admin）可见
- 页面顶部 Tab：「个人」/ 「管理」，默认落在「个人」（与员工视角一致）
- 「管理」区按角色展示对应层级：
  - `dept_admin`：部门总量卡片 + 成员用量排行表 + 趋势图
  - `studio_admin`：工作室总量 + 各部门用量排行 + 成本占比饼图
  - `admin`：全公司概览 + 工作室排行 + 面包屑下钻（公司→工作室→部门→成员）
- 面包屑下钻：点击工作室进入部门排行，点击部门进入成员排行，支持返回上级
- 时间维度：日/周/月切换（复用现有趋势图组件）

## 修改需求

### M1. 侧边栏导航扩展（P0）

- 原：侧边栏含渠道、模型、模型组、Key、Catalog、健康监控、系统设置
- 改：新增「组织管理」（admin 可见）、「用量看板」（管理角色可见）两个入口
- 导航权限控制：根据当前用户角色动态显示/隐藏菜单项

### M2. 用量页与看板整合（P1）

- 原：`/admin/usage` 仅有个人用量
- 改：在用量页顶部增加 Tab「个人 / 管理」；普通员工仅见个人 Tab；管理角色两个 Tab 均可见
