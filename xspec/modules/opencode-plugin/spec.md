## 1. 业务背景与目标

为使用 OpenCode IDE 的研发人员提供零配置的模型接入体验。通过一键安装脚本和自动模型发现，让用户在 OpenCode 中无需手动配置即可使用公司网关的所有模型。

- **业务背景**：OpenCode 是公司研发人员的主要 AI IDE，需要与 LLM Gateway 无缝对接
- **核心目标**：实现一键安装、模型自动发现、配置静默更新
- **成功指标**：
  - 安装流程 < 2 分钟
  - 模型列表自动同步，无需手动编辑配置
  - 新模型上线后 5 分钟内对 OpenCode 用户可见

---

## 2. 关键概念

- **插件 Bundle**：打包好的 OpenCode 模型发现插件，通过控制面分发
- **安装脚本**：一键执行的 shell 脚本，负责下载插件 bundle 并安装到 `~/.config/opencode/plugins/`
- **模型发现**：插件周期性地从控制面拉取模型列表，自动更新 OpenCode 的可用模型配置
- **控制面 API**：`/api/v1/opencode-config` 系列接口，提供安装脚本生成和插件 bundle 下载

---

## 3. 超出范围

- 不包含 OpenCode IDE 本身的功能开发
- 不包含其他 IDE（VS Code、Cursor）的适配
- 不包含插件的 UI 界面开发
- 不包含用户级模型使用统计分析

---

## 4. 功能描述

### 4.1 一键安装

**说明**：用户通过控制面管理后台获取安装脚本，在终端执行后自动完成插件安装和初始配置。

**输入**：用户在管理后台点击"生成安装脚本"，获得一段可执行的 shell 命令

**输出**：
- 插件 bundle 下载并安装到 `~/.config/opencode/plugins/`
- 插件自动注册到 OpenCode 的插件系统
- 自动拉取初始模型列表并写入配置

**异常与边界**：
- **网络不可达**：安装脚本失败，提示用户检查网络和控制面地址
- **目录不存在**：自动创建 `~/.config/opencode/plugins/` 目录
- **权限不足**：提示用户检查目录写入权限
- **已有旧版本**：覆盖安装旧版本，保留用户自定义配置

### 4.2 模型自动发现

**说明**：插件周期性地从控制面 `/api/v1/opencode-config` 接口拉取当前可用的模型列表，并更新 OpenCode 的模型配置，确保用户在 OpenCode 的模型选择器中看到最新模型。

**输入**：插件定时触发（默认 5 分钟）或手动触发

**输出**：
- 模型列表更新到 OpenCode 配置中
- OpenCode 模型选择器展示最新模型

**异常与边界**：
- **控制面不可达**：保留上次成功拉取的模型列表，标记"可能过期"
- **模型列表为空**：不更新配置，保留旧列表
- **配置解析失败**：记录错误日志，保留旧配置不变

### 4.3 插件版本自更新

**说明**：插件检测到控制面有新版本时，自动下载并更新，无需用户手动干预。

**输入**：每次定时拉取时检查版本号

**输出**：自动下载新版本 bundle，重启插件应用更新

### 4.4 macOS URL Scheme 助手

**说明**：`cmd/opencode-helper` 二进制，通过 macOS 自定义 URL Scheme 实现从浏览器一键触发 OpenCode 的模型配置更新。

**输入**：用户点击浏览器中的 `opencode-helper://` 链接

**输出**：触发 OpenCode 插件立即刷新模型列表

---

## 5. 非功能需求

- **性能**：模型列表拉取 < 1s，插件 bundle 下载 < 5s
- **可靠性**：控制面不可达时降级到缓存列表，不影响用户正常使用
- **安全性**：安装脚本和插件 bundle 通过 HTTPS 传输，控制面地址可配置
- **可维护性**：插件版本在 `tools/opencode-models-discovery/package.json` 中管理，更新后 bump 版本并 `bun run build:bundle`

---

## 6. 验收标准

| 编号 | 关联 | Given（前置状态） | When（触发动作） | Then（预期结果） | 优先级 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| AC-01 | 安装 | Given 用户未安装插件，网络可达控制面 | When 在终端执行安装脚本 | Then 插件安装成功，模型列表在 OpenCode 中可用 | P0 |
| AC-02 | 发现 | Given 插件正常运行，控制面有新模型上线 | When 插件定时拉取 | Then 5 分钟内新模型出现在 OpenCode 模型选择器中 | P0 |
| AC-03 | 降级 | Given 控制面不可达 | When 插件尝试拉取模型列表 | Then 使用上次缓存的列表，标记可能过期 | P1 |
| AC-04 | 自更新 | Given 控制面插件版本高于本地 | When 插件执行定时检查 | Then 自动下载并安装新版本 | P1 |

---

## 7. 假设与依赖

- 假设 OpenCode IDE 的插件接口保持稳定
- 依赖 control-plane 模块提供 `/api/v1/opencode-config` 系列接口
- 假设用户终端有 `curl` 或 `wget` 可用
- macOS URL Scheme 仅 macOS 平台可用
